# Customer_Shopping_Behavior-
End-to-end customer shopping behavior analysis using Python for data cleaning, SQL for business insights, and Power BI for interactive executive dashboards.
---
## 📊 Project Overview
This project analyzes transactional customer data (3,900 purchases) to uncover patterns in spending, product preferences, demographics, and subscription behavior. The end-to-end workflow covers data cleaning, relational database querying, interactive dashboarding, and executive presentation design.
---
## 🛠️ Tech Stack & Tools
* **Python (Pandas):** Data cleaning, missing value imputation, and feature engineering.
* **PostgreSQL / SQL:** Relational database integration and business intelligence querying.
* **Power BI:** Interactive executive dashboard visualization.
* **Gamma AI:** Executive presentation generation.
---
## 📈 Key Insights & Findings
* **Revenue Drivers:** **Clothing** leads category revenue (~$100K, ~1,700 sales), followed by **Accessories** (~$75K). **Young Adults** contribute the highest revenue segment ($62,143).
* **Customer Loyalty:** **80%** of customers fall into the loyal segment, with an average review rating of **3.75**.
* **Shipping Impact:** Express shipping slightly increases average order value ($60.48 vs $58.46 for standard shipping).
* **Discount Patterns:** 839 customers used discounts while still maintaining a spend higher than the overall average purchase amount ($59.76).
